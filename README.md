# Gêmeo digital · detector multigás com bomba

Simulador didático em Three.js de um detector de 4 gases (H₂S, CO, O₂, LEL) do tipo GasAlertMax XT II, para cursos de Segurança do Trabalho.
Sem afiliação com o fabricante.

- Simulador: `index.html` (abra com `?demo=1` para a demonstração narrada pela voz Francisca/pt-BR)
- Histórico: `versoes.html`
- Rodar localmente: `node tools/serve.mjs 8801` → http://localhost:8801/
